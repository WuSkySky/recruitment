## AI Agent 辅助学习与开发
本次招新计划**建立在使用 AI Agent 辅助学习和开发的基础上**。我们强烈建议大家使用 AI Agent，推荐 DeepSeek Harness、Codex 等工具。使用 AI 在AI辅助下学习开发是现代开发者需要具备的能力。**这是最核心的建议请重视**

AI Agent 在开发和学习中可以进行全流程辅助：

# 学习主题
本阶段的学习内容主要面向机器人软件开发，分为 RM、RC 赛事与机器人开发流程、STM32 嵌入式开发和 ROS 2 机器人开发三个主题。嵌入式与 ROS 2 分别对应机器人软件系统的底层和上层，赛事、机器人及开发流程的学习则帮助大家了解实际需求从何而来，以及不同技术模块如何围绕比赛任务协同工作。

## （一）RM、RC 赛事，机器人及开发流程
机器人开发需要从实际任务出发。了解 RoboMaster（RM）与 ROBOCON（RC）的比赛内容和规则，有助于理解机器人为什么需要相应的机械结构、传感器、执行器、控制系统和算法，也能够帮助大家认识自己所学内容在整台机器人中的作用。

报名同学需要了解两项赛事的主要特点和当前赛季规则，认识比赛机器人的基本组成以及各个模块之间的关系。在此基础上，了解一台机器人如何从规则分析和需求确定开始，经过方案设计、分模块开发、测试与整机联调，最终走上赛场。

只需要对RM，RC有大概了解，简单熟悉机器人组成，了解开发流程。

### 主要内容：
1. RM 与 RC 的比赛内容和主要特点
2. 当前赛季的主要规则、比赛任务
3. 各类机器人的特点与分工
4. 机械、电气、嵌入式与上层软件之间的接口和协作关系
5. 了解机器人的机械结构、电气系统、传感器、执行器和计算控制设备，了解这些组件间的关系
6. 了解上位机-下位机的架构
7. 了解机器人驱动、通信、感知、决策和控制等软件模块及他们的关系
8. 机器人从需求分析、方案设计、模块开发到整机联调和赛场测试的基本流程

### 希望能回答下面的问题：
1. RM、RC 中有哪些机器人？分别承担什么任务？
2. 一台完整的比赛机器人通常由哪些部分组成？你会怎么分类？
3. 哪些任务适合上位机，哪些适合下位机？
4. 机器人是怎么完成一项任务的（如 RM 中瞄准装甲板发射弹丸）？

## （二）stm32 嵌入式开发
嵌入式是机器人软件系统中与硬件交互最直接的一层。机器人对电机、传感器和执行机构的控制，以及不同硬件模块之间的数据交换，通常都离不开嵌入式系统。

通过实际操作了解单片机的基本组成和工作原理，熟悉程序编写、编译、烧录和调试的基本流程。在此基础上，学习常用外设的作用及使用方法，常用通信协议。

学习过程中不要求掌握所有外设和通信协议，更重要的是理解单片机如何读取外部信息、处理数据并控制硬件，以及如何借助数据手册、开发文档和调试工具解决实际问题。

### 环境准备：
1. stm32 单片机开发板
2. 烧录器
3. LED，按钮等传感器，执行器
4. 面包板、杜邦线、USB 数据线等连接工具；
5. USB 转串口模块
6. 开发工具链，建议 linux + CubeMX + vscode + stm32-for-vscode 插件

### 主要内容：
1. 单片机的基本组成与程序运行过程
2. 开发环境配置以及程序的编写、编译、烧录和调试
3. 原理图与数据手册阅读与使用
4. GPIO、中断、定时器等常用外设
5. UART、CAN、USB VCP 等常用通信协议
6. 嵌入式程序的模块划分与基础故障排查

### 希望能回答下面的问题：
1. 开发板、MCU、CPU、外设之间有什么关系？
2. 让 stm32 执行一段你设计的程序，步骤是什么？
3. 使用 stm32 驱动一个设备（如LED）的过程是什么样的？
4. 如何调试一个功能，功能出现问题怎么办（如调试LED闪烁功能）？

## （三）ROS 2 机器人开发
ROS 2 是一套成熟的机器人软件开发框架。它能够将感知、控制、决策和可视化等功能拆分为相对独立的模块，并通过统一的通信机制将这些模块连接起来，便于多人协作开发、调试和复用。

希望同学们了解 ROS 2 的基本特点，程序组织方式以及运行方式。随后ros2中的通信方式，理解不同节点之间如何交换数据和协同运行。并熟悉常用调试，可视化工具，能够查看节点运行状态、检查通信数据、调整参数并对机器人状态进行可视化。

学习重点不是记忆接口名称，调用方法，cli命令，也不是具体某个工具的使用方法。而是，建立对机器人上层软件的整体认识，熟悉用ros2组织的机器人系统和机器人系统调试思路。

### 环境准备：
1. linux系统，建议使用双系统
2. ros2，rviz2，rqt

### 主要内容：
1. Linux 基本操作与 ROS 2 环境配置
2. ROS 2 的特点及其在机器人开发中的作用
3. 工作空间、功能包和节点的组织方式
4. 话题、服务、动作和参数等通信机制
5. ROS 2 功能包的创建、编译和运行
6. ros2 cli、rviz、qrt 等调试与可视化工具

### 希望能回答下面的问题：
1. 使用ros2 解决了机器人软件系统中的哪些问题？
2. 从一个空的工作空间，到运行一个节点，流程是什么？
3. 如何调试一个功能，功能出现问题怎么办（如调试识别物体并夹取这个链路）？

## 1. 状态监测可视化系统
监测机器人系统的运行状态，环境状态或用户输入，根据这些信息控制LED、蜂鸣器等设备，提醒用户，并结合ros2可视化显示。

## 2. 云台目标跟踪
摄像头识别目标并计算目标位置，下发云台控制指令，控制舵机或电机，使云台跟随目标运动。

## 3. 手势控制夹爪
摄像头识别手势，并将识别结果转换为夹爪控制指令，控制舵机完成夹爪的张开、闭合或其他动作。
